# design-sprites

A design sprite is a standalone web app (Next.js + TypeScript) that hosts one design Project: an append-only verbatim record, a chat + question-card UI, and a deterministic state machine with an MCP server — and **no built-in AI**. The interviewer is an external agent (Muse or Claude Code) driving the sprite over MCP: predicting every answer, asking only where its guess is weak, judging each prediction hit or miss, and re-deriving a living decision model (`model.md`) from the verbatim record. When the deterministic sharpness gate passes, the driver declares the model sharp; the human presses Commit, and the deliverable (model, record, transcript) freezes as an exportable bundle.

v3.5 adds a `preview` question type (2–4 sandboxed, script-free HTML-snippet variants plus slider dials, driven through the same MCP turn protocol) and makes dark/light always follow the OS/browser `prefers-color-scheme` — theme tokens only, no toggle or setting. v3.6 adds a batch-answering flow (Next open question + "N of M answered" header progress; the pane never auto-closes or auto-advances on save), a jump-to-question navigator (Questions section, status only), a sticky chat composer docked to the chat column, mobile round 2 (sticky Save bar in the answer pane, dial touch targets at least 44px), and an optional driver-side ds-wake bridge (`template/tools/ds-wake/`) that wakes a Claude Code driver session via Channels, with `wait_for_input` as the fallback.

**The skill is [SKILL.md](SKILL.md)** — read it, or hand it to any coding agent: `Read vicyap/design-sprites/SKILL.md`.

Layout:

- `SKILL.md` — the canonical skill (v3.6; copy-paste ready).
- `brief.md` — the founding brief (v1, 2026-11-11), kept verbatim for the record; where it describes rounds, submit, or email, SKILL.md (v3.6) supersedes it.
- `template/` — the v3.6 sprite app template (Next.js 15 + React 19 + TypeScript; Drizzle + SQLite on the sprite disk; MCP over Streamable HTTP; app `design_sprite`, version 3.6.0-p3), including its `DEPLOY.md` runbook and the optional `tools/ds-wake/` Channels bridge. v3.6 sprites need **no `conn:*` labels** — the app makes no AI calls.
- `.claude/skills/design-sprites/SKILL.md` — a symlink to the root `SKILL.md`, so Claude Code sessions mounting this repo discover the skill automatically. One canonical file; the link never drifts.
